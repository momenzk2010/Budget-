# ميزانيتي — تطبيق إدارة الراتب والمصاريف

مشروع جاهز (Vite + React + Tailwind) قابل للنشر كتطبيق ويب حقيقي (PWA)
يشتغل على أكثر من جهاز، ويعمل offline.

## ١. التجربة على جهازك أول

```bash
npm install
npm run dev
```

بيفتحلك رابط محلي (مثلاً `http://localhost:5173`) تقدر تجربه من المتصفح.

## ٢. رفعه على GitHub

```bash
git init
git add .
git commit -m "أول نسخة من تطبيق الميزانية"
```

بعدين سوي مستودع (repository) جديد وفاضي على GitHub، وانسخ الأوامر اللي بيعطيكها
(`git remote add origin ...` ثم `git push -u origin main`).

## ٣. النشر على Vercel (مجاني)

1. روح [vercel.com](https://vercel.com) وسجل دخول بحساب GitHub
2. "Add New Project" → اختر المستودع اللي رفعته
3. Vercel بيتعرف على إعدادات Vite تلقائيًا — بس دوس "Deploy"
4. بعد دقيقة بيعطيك رابط زي `budget-app.vercel.app`

كل ما تعدّل الكود وتعمل `git push`، بينشر التحديث تلقائيًا.

## ٤. تثبيته كتطبيق على الجوال

- افتح رابط Vercel من متصفح الجوال (كروم على أندرويد أو سفاري على آيفون)
- كروم: من القائمة (⋮) اختر "إضافة إلى الشاشة الرئيسية" / "تثبيت التطبيق"
- سفاري: من زر المشاركة اختر "إضافة إلى الشاشة الرئيسية"
- بتصير عندك أيقونة زي أي تطبيق عادي، وبيفتح بدون شريط المتصفح
- بما إنه PWA، بيشتغل حتى وانت أوفلاين (البيانات محفوظة محليًا بكل جهاز)

## ٥. الكاميرا ومسح الباركود

بعد النشر، الكاميرا وقراءة الباركود (BarcodeDetector) والاتصال بـ Open Food Facts
رح تشتغل بشكل طبيعي في المتصفحات الداعمة (خصوصًا كروم على أندرويد) — لأنه ما رح
يكون في أي حماية (sandbox) تحجب الشبكة زي ما كان صايرة جوا Claude.

> ملاحظة: BarcodeDetector مو مدعومة على كل المتصفحات (مثلاً سفاري على آيفون
> لسا ما يدعمها بشكل كامل) — بهالحالة التطبيق بيرجع تلقائيًا لخيار الكتابة اليدوية.

## ٦. مزامنة البيانات بين أكثر من جهاز (الخطوة الجاية)

هلق كل جهاز يخزّن بياناته لحاله محليًا (localStorage) — يعني ما تتزامن بين
جوالين مختلفين تلقائيًا. لو بدك هالشي:

1. سوي مشروع مجاني على [Firebase](https://firebase.google.com) (Firestore) أو
   [Supabase](https://supabase.com)
2. فعّل تسجيل دخول بسيط (Anonymous Auth أو إيميل/كلمة سر)
3. بدّل محتوى `src/storage.js` بحيث `get`/`set` تقرأ/تكتب من قاعدة البيانات
   السحابية بدل `localStorage` — البنية جاهزة ومعزولة بملف واحد بالضبط لهيك.

خبرني وقت ما توصل لهالمرحلة وبساعدك تكتب كود الربط مع Firebase أو Supabase.

## بنية المشروع

```
budget-pwa/
├── src/
│   ├── App.jsx          ← التطبيق الكامل (كل الصفحات والمكونات)
│   ├── storage.js        ← طبقة التخزين (localStorage، جاهزة تتبدّل لاحقًا)
│   ├── main.jsx
│   └── index.css
├── public/icons/          ← أيقونات التطبيق (استبدلها بشعارك لو حبيت)
├── vite.config.js         ← إعدادات PWA (التثبيت + العمل أوفلاين)
├── tailwind.config.js
└── package.json
```
